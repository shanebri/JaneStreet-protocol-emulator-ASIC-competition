# JaneStreet-protocol-emulator-ASIC-competition

Starter HDL imported from [TinyTapeout/ttihp-verilog-template, branch `cmos5l`](https://github.com/TinyTapeout/ttihp-verilog-template/tree/b86a2a781484bcab7ba522dc5de540086695a430). Upstream commit: `b86a2a781484bcab7ba522dc5de540086695a430`.

The [Jane Street competition](https://blog.janestreet.com/protocol-emulator-asic-competition/) targets IHP CMOS5L; `info.yaml` is configured for 6x4 tiles. The HDL and testbench remain the upstream example adder, ready to be replaced with the protocol emulator. Fill in the project metadata, choose a unique top module name, and complete the datasheet before submission.

The repository's original MIT license is retained in [LICENSE](LICENSE). Imported Tiny Tapeout template files retain their Apache-2.0 license in [LICENSE-TinyTapeout](LICENSE-TinyTapeout) and their original notices.

## What is Tiny Tapeout?

Tiny Tapeout is an educational project that aims to make it easier and cheaper than ever to get your digital and analog designs manufactured on a real chip.

To learn more and get started, visit https://tinytapeout.com.

## Set up your Verilog project

1. Add your Verilog files to the `src` folder.
2. Edit the [info.yaml](info.yaml) and update information about your project, paying special attention to the `source_files` and `top_module` properties. If you are upgrading an existing Tiny Tapeout project, check out our [online info.yaml migration tool](https://tinytapeout.github.io/tt-yaml-upgrade-tool/).
3. Edit [docs/info.md](docs/info.md) and add a description of your project.
4. Adapt the testbench to your design. See [test/README.md](test/README.md) for more information.

The GitHub action will automatically build the ASIC files using [LibreLane](https://www.zerotoasiccourse.com/terminology/librelane/).
